<section class="faq"><p class="eyebrow">QUESTIONS FRÉQUENTES</p><h2>À savoir avant l’import</h2><details><summary>Je n’ai pas de fichier XML : comment créer une sauvegarde ?</summary><p>Sur Android, installez SMS Backup &amp; Restore, créez une sauvegarde locale des messages au format XML, puis transférez le fichier sur votre appareil. <a href="{{ '/guides/creer-sauvegarde-sms-android/' | relative_url }}">Voir le guide pas à pas →</a></p></details><details><summary>Mes anciens SMS vont-ils apparaître dans l’app Messages de l’iPhone ?</summary><p>Non. Archive SMS les affiche dans son propre lecteur et permet de les rechercher; l’application ne les réinjecte pas dans Messages.</p></details><details><summary>Et si je n’ai plus l’ancien Android ni de sauvegarde ?</summary><p>Archive SMS a besoin d’un fichier XML existant. Elle ne peut pas récupérer des messages qui n’ont pas été sauvegardés.</p></details><details><summary>J’ai un téléphone professionnel : puis-je exporter les SMS ?</summary><p>Vérifiez d’abord les règles de votre entreprise et demandez à votre service informatique si besoin. Utilisez uniquement un moyen de transfert autorisé et évitez les clouds personnels pour les messages professionnels.</p></details><details><summary>Quels fichiers puis-je ouvrir ?</summary><p>Le lecteur accepte les fichiers XML exportés par SMS Backup &amp; Restore.</p></details><details><summary>Est-ce que ça fonctionne sur iPhone ?</summary><p>Oui. Ouvrez le site dans Safari et choisissez votre fichier XML. Les noms des contacts et les MMS s’affichent lorsqu’ils sont inclus dans la sauvegarde.</p></details><details><summary>Mes messages sont-ils envoyés en ligne ?</summary><p>Non. Le fichier est lu dans le navigateur et l’archive est conservée sur votre appareil. Si vous transférez le XML via un cloud, il suit les réglages de ce service.</p></details><details><summary>Un gros fichier peut-il être importé ?</summary><p>Le lecteur traite le XML progressivement. La capacité dépend aussi de l’espace disponible et des limites du navigateur.</p></details></section>
