<section class="faq"><p class="eyebrow">FREQUENTLY ASKED</p><h2>Before you import</h2><details><summary>I don’t have an XML file yet. How do I create a backup?</summary><p>On Android, install SMS Backup &amp; Restore, create a local XML backup of your messages, then transfer the file to your device. <a href="{{ '/en/guides/create-sms-backup-android/' | relative_url }}">Follow the step-by-step guide →</a></p></details><details><summary>Will my old texts appear in the iPhone Messages app?</summary><p>No. SMS Archive displays and lets you search them in its own reader; it does not add them back to Messages.</p></details><details><summary>What if I no longer have the old Android phone or a backup?</summary><p>SMS Archive needs an existing XML file. It cannot recover messages that were never backed up.</p></details><details><summary>Can I export texts from a work phone?</summary><p>Check your employer’s rules and ask IT if needed. Use only an approved transfer method, and avoid personal cloud storage for work messages.</p></details><details><summary>Which files can I open?</summary><p>The reader accepts XML files exported by SMS Backup &amp; Restore.</p></details><details><summary>Does it work on iPhone?</summary><p>Yes. Open the site in Safari and choose your XML file. Contact names and MMS appear when included in the backup.</p></details><details><summary>Are my messages uploaded?</summary><p>No. The file is read in your browser and the archive is stored on your device. If you transfer the XML through a cloud service, that service’s settings apply.</p></details><details><summary>Can I import a large file?</summary><p>The reader processes XML progressively. Available storage also depends on your device and browser limits.</p></details></section>
