<section class="page-hero"><p class="eyebrow">MAC GUIDE</p><h1>Open an SMS XML file on Mac</h1><p class="lead">Read an XML backup in your browser without installing conversion software.</p></section><article class="article"><h2>1. Find your backup</h2><p>Locate the XML file exported by SMS Backup &amp; Restore. If it is on your phone, transfer it to your Mac using AirDrop, iCloud Drive, or a cable.</p><h2>2. Open the reader</h2><p>In Safari, Chrome, or another recent browser, open <a href="{{ '/app/' | relative_url }}">the SMS Archive reader</a>.</p><h2>3. Import the XML</h2><p>Click Import and select the file in Finder. Keep the browser tab open until the import finishes.</p><h2>4. Find your messages</h2><p>Choose a conversation or use search. Displayed information depends on what is included in the XML file.</p><p>A copy of the archive is saved in this browser’s storage on your Mac. Delete it from the app when you no longer need it.</p></article>
