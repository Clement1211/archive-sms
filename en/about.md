<section class="page-hero"><p class="eyebrow">ABOUT</p><h1>A simple reader for your old conversations.</h1><p class="lead">SMS Archive turns an XML backup into conversations you can browse on iPhone, Mac, and computer.</p></section><article class="article"><h2>Why this project exists</h2><p>SMS backups are useful, but XML is not designed to be read by hand. SMS Archive helps you find a conversation without sending your file to a conversion service.</p><h2>How it works</h2><p>Select an SMS Backup &amp; Restore XML file. Your browser reads it progressively and stores the archive on the device you use. Contact names and MMS attachments appear when present in the backup.</p><h2>Open source</h2><p>The source code is published under the MIT license. Visit GitHub to report a problem or suggest an improvement.</p><p><a href="https://github.com/Clement1211/archive-sms">View the project on GitHub →</a></p><p><a class="button primary" href="{{ '/app/' | relative_url }}">Open the reader</a></p></article>
