Comment exporter vos SMS depuis Android ?

1. Installez SMS Backup & Restore

Téléchargez l’application depuis le Play Store :

Disponible sur Google Play

2. Créez une sauvegarde XML

  1. Ouvrez l’application.
  2. Autorisez l’accès aux SMS.
  3. Choisissez « Sauvegarder » ou « Backup ».
  4. Choisissez le format XML (pas JSON).
  5. Sélectionnez les conversations à exporter.
  6. Lancez la sauvegarde.

3. Trouvez votre fichier XML

Le fichier se trouve généralement dans le dossier /SMS Backup Restore/ de votre stockage interne.

Exemple : sms-backup-2024.xml

4. Transférez le fichier vers cet appareil

Par exemple par e-mail, via un espace de stockage en ligne ou par câble USB.

5. Importez le fichier ici

Choisissez « Importer » et sélectionnez votre fichier XML.

Astuce : ajoutez l’application à l’écran d’accueil pour y accéder rapidement.

Important : vos SMS restent sur cet appareil. Aucune donnée n’est envoyée vers un serveur.
