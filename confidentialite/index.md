<section class="page-hero"><p class="eyebrow">CONFIDENTIALITÉ</p><h1>Vos messages restent sur l’appareil.</h1><p class="lead">Le lecteur traite votre sauvegarde dans le navigateur. Le contenu des messages n’est pas envoyé à Archive SMS.</p></section><article class="article"><h2>Fichier et archive</h2><p>Le fichier XML est lu par le navigateur. Les conversations importées sont stockées dans la base IndexedDB de ce navigateur sur cet appareil. Les limites de stockage dépendent du navigateur et de l’appareil.</p><h2>Connexion au site</h2><p>Comme tout site web, l’hébergement peut traiter des données techniques de connexion selon sa propre politique. Archive SMS ne reçoit pas le contenu du fichier importé.</p><h2>Suppression</h2><p>Utilisez le bouton « Supprimer » dans le lecteur pour effacer l’archive enregistrée sur cet appareil. Supprimer les données du site dans les réglages du navigateur efface également cette copie.</p><h2>Contact</h2><p>Pour une question sur cette politique, consultez la page <a href="{{ '/contact/' | relative_url }}">Contact</a>.</p></article>
