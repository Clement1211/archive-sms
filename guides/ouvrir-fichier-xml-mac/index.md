<section class="page-hero"><p class="eyebrow">GUIDE MAC</p><h1>Ouvrir un fichier XML SMS sur Mac</h1><p class="lead">Lisez une sauvegarde XML dans votre navigateur, sans installer de logiciel de conversion.</p></section><article class="article"><h2>1. Préparez votre sauvegarde</h2><p>Repérez le fichier XML exporté par SMS Backup &amp; Restore. Si la sauvegarde se trouve sur votre téléphone, transférez-la sur le Mac avec AirDrop, iCloud Drive ou un câble.</p><h2>2. Ouvrez le lecteur</h2><p>Dans Safari, Chrome ou un navigateur récent, ouvrez <a href="{{ '/app/' | relative_url }}">le lecteur Archive SMS</a>.</p><h2>3. Importez le XML</h2><p>Cliquez sur « Importer » et sélectionnez le fichier dans Finder. Laissez l’onglet ouvert jusqu’à la fin de l’import.</p><h2>4. Retrouvez vos messages</h2><p>Choisissez une conversation ou utilisez la recherche. Les informations affichées dépendent des données incluses dans le fichier XML.</p><p>Une copie de l’archive est enregistrée dans le stockage du navigateur sur ce Mac. Supprimez-la depuis l’app si vous n’en avez plus besoin.</p></article>
