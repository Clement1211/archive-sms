<section class="page-hero"><p class="eyebrow">GUIDE IPHONE</p><h1>Lire une sauvegarde SMS sur iPhone</h1><p class="lead">Transférez le fichier XML sur votre iPhone, puis ouvrez-le dans le lecteur avec Safari.</p></section><article class="article"><h2>1. Transférer le fichier XML</h2><p>Envoyez la sauvegarde depuis votre ordinateur ou téléphone Android vers l’iPhone avec AirDrop, iCloud Drive ou un autre moyen de transfert. Vérifiez qu’elle apparaît dans l’app Fichiers.</p><h2>2. Ouvrir Archive SMS dans Safari</h2><p>Visitez Archive SMS et touchez <a href="{{ '/app/' | relative_url }}">Ouvrir le lecteur</a>. Safari est recommandé pour l’import et l’installation sur l’écran d’accueil.</p><h2>3. Importer la sauvegarde</h2><p>Dans l’app, touchez « Importer », choisissez le fichier XML dans Fichiers et laissez l’import se terminer. Gardez Safari ouvert pendant l’opération.</p><h2>4. Parcourir les conversations</h2><p>Utilisez la recherche pour retrouver un contact ou un message. Les noms de contacts et médias MMS s’affichent quand ils sont présents dans l’export.</p><h2>Installer l’app sur l’écran d’accueil</h2><p>Dans Safari, ouvrez le menu Partager puis choisissez « Sur l’écran d’accueil ». L’icône lance directement le lecteur.</p><p>La durée d’import et l’espace disponible varient selon l’appareil et la taille de la sauvegarde. Conservez le fichier XML original.</p></article>
