<section class="page-hero"><p class="eyebrow">GUIDE DÉBUTANT · ANDROID</p><h1>Créer une sauvegarde SMS avec SMS Backup &amp; Restore</h1><p class="lead">Vous n’avez pas encore de fichier à importer ? Créez d’abord une sauvegarde XML sur le téléphone Android qui contient vos messages.</p></section>
<article class="article">
  <h2>Avant de commencer</h2>
  <p>SMS Backup &amp; Restore fonctionne sur Android. Installez l’application officielle <a href="https://play.google.com/store/apps/details?id=com.riteshsahu.SMSBackupRestore" rel="noopener noreferrer">depuis Google Play</a> sur le téléphone qui contient les SMS.</p>
  <p>Les noms des écrans peuvent varier un peu selon la version de l’application et d’Android. Pour ce site, il faut un fichier XML de messages. Les journaux d’appels sont facultatifs.</p>

  <h2>1. Lancez une nouvelle sauvegarde</h2>
  <p>Ouvrez SMS Backup &amp; Restore et touchez <strong>Backup</strong> ou <strong>Sauvegarder</strong>. Si l’application le demande, autorisez l’accès aux SMS. Autorisez aussi l’accès aux contacts si vous voulez inclure les noms enregistrés dans le téléphone.</p>

  <h2>2. Choisissez les messages et les MMS</h2>
  <p>Sélectionnez les messages SMS. Pour inclure les photos, vidéos et conversations de groupe MMS, vérifiez que l’option MMS est activée dans <strong>Menu → Settings → Backup Settings → Turn on MMS</strong> (les libellés peuvent être traduits selon la langue de l’application).</p>

  <h2>3. Gardez la sauvegarde sur le téléphone</h2>
  <p>Choisissez une sauvegarde locale sur l’appareil. L’application crée un fichier XML; l’emplacement exact dépend de ses réglages et de la version d’Android. Vous pourrez le partager depuis l’application après sa création.</p>

  <h2>4. Attendez la fin et partagez le fichier</h2>
  <p>Lancez la sauvegarde et attendez la confirmation de réussite. Ensuite, ouvrez <strong>Menu → View backups</strong>, choisissez l’onglet <strong>Local</strong>, touchez le menu ⋮ à côté de la sauvegarde, puis <strong>Send File</strong>. Sélectionnez un moyen de transfert, par exemple Google Drive ou une autre option de partage accessible depuis vos appareils.</p>
  <p>Pour un fichier volumineux, évitez les pièces jointes de courriel qui peuvent avoir une limite de taille. Si vous utilisez un service cloud pour le transfert, le fichier y sera conservé selon les réglages de ce service.</p>

  <h2>5. Téléchargez le XML sur l’appareil de lecture</h2>
  <p>Sur iPhone, retrouvez ou téléchargez le fichier dans l’app <strong>Fichiers</strong>. Sur Mac ou ordinateur, enregistrez-le dans un dossier facile à retrouver. Gardez l’extension <strong>.xml</strong>.</p>

  <h2>6. Importez-le dans Archive SMS</h2>
  <p>Ouvrez <a href="{{ '/guides/lire-sauvegarde-iphone/' | relative_url }}">le guide iPhone</a> pour transférer et importer le fichier, ou ouvrez directement <a href="{{ '/app/' | relative_url }}">le lecteur Archive SMS</a>, touchez « Importer » et choisissez le XML.</p>

  <h2>Si une conversation ou un MMS manque</h2>
  <p>Vérifiez que l’application a l’autorisation SMS, que les contacts sont autorisés si vous souhaitez leurs noms, et que MMS est activé pour les médias et les groupes. Archive SMS ne peut afficher que ce qui a été écrit dans le fichier XML.</p>
  <p>Consultez aussi la <a href="https://www.synctech.com.au/sms-backup-restore/sms-faqs/" rel="noopener noreferrer">FAQ officielle de SyncTech</a> ou la fiche <a href="https://play.google.com/store/apps/details?id=com.riteshsahu.SMSBackupRestore" rel="noopener noreferrer">SMS Backup &amp; Restore sur Google Play</a>.</p>
