<section class="page-hero"><p class="eyebrow">À PROPOS</p><h1>Un lecteur simple pour vos anciennes conversations.</h1><p class="lead">Archive SMS transforme une sauvegarde XML en conversations faciles à parcourir sur iPhone, Mac et ordinateur.</p></section><article class="article"><h2>Pourquoi ce projet existe</h2><p>Les sauvegardes SMS sont utiles, mais leur format XML n’est pas conçu pour être lu à la main. Archive SMS aide à retrouver une conversation sans envoyer le fichier à un service de conversion.</p><h2>Comment ça fonctionne</h2><p>Choisissez un fichier XML de SMS Backup &amp; Restore. Le navigateur le lit progressivement et enregistre l’archive sur l’appareil utilisé. Les noms et les pièces jointes MMS s’affichent lorsqu’ils figurent dans la sauvegarde.</p><h2>Projet open source</h2><p>Le code est publié sous licence MIT. Consultez le dépôt ou signalez un problème sur GitHub.</p><p><a href="https://github.com/Clement1211/archive-sms">Voir le projet sur GitHub →</a></p><p><a class="button primary" href="{{ '/app/' | relative_url }}">Ouvrir le lecteur</a></p></article>
