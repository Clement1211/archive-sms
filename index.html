Confidentialité

100% Local : Aucune donnée ne quitte votre navigateur.

Stockage : Vos SMS sont sauvegardés dans IndexedDB, uniquement sur cet appareil.

📱 Comment exporter vos SMS depuis Android ?

➊ Installez SMS Backup & Restore

Téléchargez l'application depuis le Play Store :

Disponible sur Google Play

➋ Créez une sauvegarde XML

  1. Ouvrez l'application
  2. Autorisez les permissions de lecture des SMS
  3. Cliquez sur "Sauvegarder" ou "Backup"
  4. Choisissez le format XML (pas JSON)
  5. Sélectionnez les conversations à exporter (ou "Tout")
  6. Lancez la sauvegarde

➌ Trouvez votre fichier XML

Le fichier est généralement sauvegardé dans : /SMS Backup Restore/ sur votre stockage interne.

Nommez-le par exemple : sms-backup-2024.xml

⍟ Transférez le fichier vers cet appareil

Plusieurs méthodes possibles :

  • ✉️ Par email
  • 📁 Via Google Drive / Dropbox
  • 🔌 Par câble USB
  • 📶 Par Bluetooth

➎ Importez le fichier ici

Cliquez sur le bouton "Importer XML" ci-dessus et sélectionnez votre fichier.

⚡ Astuce : Installez cette application sur votre écran d'accueil pour un accès rapide !

⚠️ Important : vos SMS restent 100% locaux. Aucune donnée n'est envoyée vers un serveur ou partagée avec qui que ce soit.
